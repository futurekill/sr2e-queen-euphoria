# Shadowrun 2E: Queen Euphoria

A FoundryVTT V13 content module packaging the *Queen Euphoria* adventure
(FASA 7304) for the [Shadowrun 2nd Edition system](../sr2e-foundryvtt) (`sr2e`).
The 1st-Edition adventure is **modernized to SR2E**: cast, the insect Hive, the
Strice Foods Matrix host, GM journals, and scenes, bundled as a one-click
Adventure.

Requires the `sr2e` system (≥ 0.30.0). Personal table use only — see CLAUDE.md.

## Build
```
npm install
npm run build-packs      # packs-src/ JSON -> packs/ LevelDB
npm run validate
```
